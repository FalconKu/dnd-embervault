# 余烬金库

《龙与地下城》5e（2024 规则）。矿封了三个月，矿主说是瓦斯。封矿的七个工人只回来一个，而他只肯数自己的手指。

- **人数**：3–5 人（推荐 3–4 级）
- **时长**：约 150 分钟
- **结构**：3 章 / 15 节点 / 4 个结局
- **内容**：世界书 18 条（10 条公开 / 8 条守秘人专属），地图地点 10 个
- **适用规则**：D&D 2024（`core:dnd2024`）

## 结构

| 部分 | 内容 |
|---|---|
| 第一章：断镐酒馆 | 老奥托的七根手指、镇务所的五份契约 |
| 第二章：下矿 | 矿道图、通风竖井、旧矿厅的灰壳、熔炉斜井 |
| 第三章：清账 | 炉壁上的第七个空位，四个结局 |

## 守秘人要点

1. **灰壳不要当怪物打。** 它们是「还在上班的工人」：动作整齐、没有声音、推同一辆矿车。攻击它们不会反击，只会停半秒然后继续推。这个「不反击」比任何战斗都吓人。

2. **把恐怖落在日常上。** 五年，每年一个人，全镇都知道，全镇都配合。布伦不是坏人，他只是第六年不想挑了。

3. **四个结局都有经济后果。** DnD 玩家习惯「打赢就行」，这里要让他们发现没有「打赢」，只有「选哪种代价」。

## 这个模组在讲什么

核心是一场文字游戏：矮人符文的「名」是会意字（口+刻），既指人，也指字。第五份契约因此允许「交名字」而非「交人」——这是第三条路。
